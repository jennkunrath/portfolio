# Custom AI Agent Model

**Positioning:** Solution — models a purpose-built agentic process on its own, independent of industry.

## What it's for

Per the suite's own description: "Evaluate the specific annual return on purpose-built agentic processes. Quantifies standalone throughput expansion parameters, repeatable execution loops, and direct overhead offsets." This is the generic version of the agent-value model that each vertical calculator specializes — the one to use when a stakeholder wants to evaluate an agent build on its own terms, without translating it through a specific industry's workflows, or when the use case doesn't fit one of the five vertical calculators cleanly.

## How this relates to the vertical calculators

The five vertical calculators (Financial Services, Healthcare, Professional Services, Manufacturing, Pharma) are this same underlying agent-value logic, each re-parameterized with industry-specific value-driver categories, sub-segment presets, and citation sources. This calculator is the version without that industry skin — useful for a cross-industry pitch, an internal capability demo, or a use case that doesn't map neatly onto one of the five verticals.

## Likely structure, based on the shared architecture

Following the pattern shared across the suite, this calculator keeps the same organization-profile inputs (headcount, salary, working weeks) and the same payback/ROI/grounding/ceiling machinery, but replaces the industry-specific value-driver categories with generic ones — something in the shape of throughput/output expansion, repeatable-execution-loop savings, and overhead offsets.
