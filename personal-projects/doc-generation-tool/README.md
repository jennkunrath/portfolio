# Documentation Generation Agent — public profile page

A single static page (`index.html`) presenting the project publicly: what it does, the outline → draft →
review pipeline, the four review sub-agents, features, and tech stack. No source code included.

## Use it

Open `index.html` directly in a browser, or host it anywhere that serves static files (GitHub Pages, Netlify,
Vercel, S3, your own portfolio site). It has no build step and no dependencies beyond two Google Fonts loaded
over a CDN link in the `<head>`.
