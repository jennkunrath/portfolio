# Hi, I'm Jenn Kunrath 👋

I'm an Enterprise AI Solutions Engineer. I design agent architectures and RAG systems for the
enterprise, build the prototypes that make them concrete in a customer conversation, and test them
thoroughly to see and prove what actually works.

That last item is worth focusing on given the process and structure I put around it. When I evaluate a tool, 
I set pass criteria before the build starts, test against a stratified corpus rather than a sample, and 
publish the failures next to the thresholds they missed. AI evaluations I run have a clear results table 
of what went well and an examination of what was missed and how it might be improved where such recommendations
can be extrapolated.

## 🏗️ What I do professionally

**Decoupled agent frameworks.** I design AI infrastructure aimed at the scalability gap: decoupling
the foundational agent framework from the instruction layer so an organization can write and optimize
a core once, then repurpose it across departments instead of rebuilding per use case. The
[architecture write-up](./agent-patterns) covers the patterns that held up across a production
library and what was learned through building.

**Dynamic value quantification.** Nine interactive ROI models spanning combined solution value,
custom agents, workforce impact, RAG, and five industry verticals. Built as an HTML/JavaScript
framework grounded in published McKinsey and Gartner benchmarks, so a prospect can change the inputs
mid-call and watch the case move. They work as a scoping tool as much as a selling one: the fastest
way to find out a solution isn't worth building is to model it honestly in front of the customer.

**Interface prototyping.** Production-grade front-end demos that turn an abstract architecture into
something a customer can react to. Before platforms standardized native agent instructions, I built a
middleware layer into a client-facing web UI that visually mapped how instructions routed between
agents, so customers could see the mechanism.

## 💡 Personal builds

I use natural-language prototyping to get to working software fast and where necessary, do additional engineering by hand.

- **[MindfulApp](./personal-projects/mindful-app):** an AI journaling companion built for friends who

  combining an SVM audio classifier with observed ear and tail position, and surfaces the conflict
